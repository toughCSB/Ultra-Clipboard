# macOS 캡처 편집 기능 완전 포팅

## Goal

macOS 사용자가 Ultra Clipboard의 화면 캡처와 편집 기능을 Windows 버전과 같은 제품 흐름으로 사용할 수 있게 한다. 단축키 또는 트레이에서 캡처를 시작하고, 영역·창·전체 화면·지연·반복 캡처를 거쳐 기존 편집기에서 편집한 뒤 복사·저장·화면 고정·드래그 출력까지 완료할 수 있어야 한다.

## Background

- 현재 Windows 백엔드는 화면 픽셀 캡처, 창 목록, 이전 활성 창 복원을 구현한다.
- 현재 macOS 백엔드는 명시적인 미구현 스텁이며 `is_supported()`가 `false`라서 캡처 메뉴와 단축키가 노출되지 않는다.
- 캡처 오버레이, 편집기, 화면 고정 창과 대부분의 출력 경로는 공용 React/Tauri 구현을 사용한다.
- macOS 빌드와 릴리스 산출물은 Apple Silicon 및 Intel 대상으로 이미 생성된다.
- 실제 Apple Silicon Mac에 SSH로 접근할 수 있고, 해당 Mac의 Orca 데스크톱 런타임도 사용 가능하다.
- 기준 소스는 `master`와 `origin/master`가 일치하는 `v1.2.2` 커밋 `b2f1fe771700cb5aecb4ce322ea1a01dd67c2c04`이다.

## Requirements

### R1. Windows 기능 동등성

- macOS에서 영역, 창, 전체 화면, 지연 및 마지막 영역 반복 캡처를 제공한다.
- Windows와 동일한 트레이 진입점과 설정 가능한 전역 단축키를 제공한다.
- 캡처 완료 후 기존 Screenshot Editor 흐름으로 진입한다.
- 기존 편집기의 편집 도구, 실행 취소·다시 실행, 복사, 저장, 화면 고정 및 드래그 출력을 macOS에서 사용할 수 있어야 한다.
- 편집기의 텍스트 인식(OCR)과 `⌘⇧O` 단축키를 macOS에서 제공하고, 인식 결과를 클립보드에 복사한다.

### R2. macOS 시스템 통합

- 화면 기록 권한 상태를 확인하고 사용자의 명시적인 캡처 동작에서 권한을 요청한다.
- 권한이 없거나 거부되었거나 재시작이 필요할 때 사용자가 다음 행동을 알 수 있는 안내를 제공한다.
- 창 캡처 후보에서는 Ultra Clipboard 자체 창과 시스템 바탕 화면 창을 제외한다.
- 캡처 프레임을 먼저 동결한 뒤 선택 오버레이를 표시하여 오버레이가 결과 이미지에 포함되지 않게 한다.
- 캡처 취소 및 완료 후 가능하면 이전 활성 앱으로 포커스를 복원한다.

### R3. 디스플레이 및 좌표 정확성

- Retina 및 비 Retina 디스플레이에서 선택 영역과 결과 픽셀이 일치해야 한다.
- 서로 다른 배율의 다중 모니터와 음수 전역 좌표 배치를 지원한다.
- 모니터 경계, 메뉴바, Dock, 창이 화면 밖이나 여러 화면에 걸친 경우를 안전하게 처리한다.

### R4. 성능과 안정성

- 캡처 시작부터 오버레이 표시까지의 주요 단계를 측정할 수 있어야 한다.
- 연속 캡처에서 오류, 검은 화면, 오래된 프레임, 오버레이 깜박임 또는 앱 멈춤이 없어야 한다.
- 기능 완료 판단은 단일 측정값이 아니라 동일 조건의 반복 측정과 실제 화면 확인에 근거한다.

### R5. 호환성과 회귀 방지

- macOS 최소 지원 버전은 14.0으로 한다.
- macOS Apple Silicon과 Intel 빌드가 모두 통과해야 한다.
- Windows 캡처와 편집 기능의 기존 동작이 유지되어야 한다.
- macOS 14 미만에서는 설치 및 실행이 지원되지 않도록 릴리스 설정과 문서를 일치시킨다.

### R6. 실제 기기 검증

- SSH를 통해 Mac에서 설치, 빌드 및 자동 검증을 수행한다.
- Orca의 Mac 데스크톱 제어를 통해 권한 프롬프트 이후의 실제 캡처·편집·출력 경로를 시각적으로 검증한다.
- 자동화할 수 없는 보안 프롬프트가 있으면 필요한 사용자 동작과 검증 중단 지점을 명확히 기록한다.

### R7. Windows·macOS 공통 편집기 개선

- 형광펜의 색 외에 진하기를 조절하고 새 표시와 이미 그린 표시 모두에 적용한다.
- 밝은 화면의 글자를 읽을 수 있고 어두운 화면에서도 표시가 보이는 하이라이트를 제공한다.
- 불필요한 캡처를 버리는 휴지통 버튼의 색, 크기, 명칭을 더 분명하게 만든다.
- Windows와 macOS의 미리보기·복사·저장 이미지가 같은 렌더링 결과를 사용한다.

## Acceptance Criteria

- [ ] macOS에서 캡처 메뉴와 모든 캡처 단축키가 정상적으로 제공된다.
- [ ] 화면 기록 권한의 미결정, 허용, 거부 상태가 각각 올바르게 처리된다.
- [ ] 영역·창·전체 화면·지연·반복 캡처가 실제 Mac에서 성공한다.
- [ ] 단일 Retina 및 혼합 배율 다중 모니터에서 선택 좌표와 결과 이미지가 일치한다.
- [ ] 창 캡처 후보에서 앱 자체 창과 시스템 바탕 화면 창이 제외되고, 선택 오버레이가 캡처 이미지에 포함되지 않는다.
- [ ] 기존 편집기 도구와 실행 취소·다시 실행이 macOS에서 동작한다.
- [ ] macOS Vision OCR이 한국어·영어 텍스트를 인식하고 결과를 클립보드에 복사한다.
- [ ] 편집 결과의 클립보드 복사, 파일 저장, 화면 고정 및 드래그 출력이 macOS에서 동작한다.
- [ ] 반복 캡처 성능과 시각 결과가 기록되고, 사용자 체감 지연이나 반복 실패가 남지 않는다.
- [ ] frontend lint/test와 Rust format/clippy/test가 통과한다.
- [ ] Apple Silicon 실제 기기 빌드·실행 검증과 macOS Intel 빌드 검증이 통과한다.
- [ ] Windows 자동 검증과 핵심 캡처 회귀 검증이 통과한다.
- [ ] Windows·macOS에서 형광펜 색과 진하기 조절, 선택한 표시 재편집, 삭제 버튼을 실제 편집 화면에서 확인한다.

## Out of Scope

- 화면 녹화와 오디오 녹음
- Linux 지원
- 기존 편집기와 무관한 신규 편집 도구 추가
- macOS App Store 배포 전용 샌드박스 전환
