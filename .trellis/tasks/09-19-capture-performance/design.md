# Design

- 먼저 격리된 QA 경로에서 캡처 타임라인을 측정한다. 기존 Rust Instant 로그와 UI 관찰을 활용하고 임시 계측은 제거한다.
- 프레임은 현재 Tauri 바이너리 응답이므로 base64 전환을 하지 않는다. 창 생성·표시, bounds, 렌더 준비를 각각 분석한다.
- 앱 시작·단축키·가상 목록·DB/검색·썸네일·IPC/타이머를 점검하되 측정되거나 직접 확인된 병목만 수정한다.
- 저장 스키마와 released migrations는 유지한다. 인덱스가 필요하다는 근거가 충분할 때만 새 migration을 고려한다.
- 캡처 상태·이벤트 계약을 유지하고 양 플랫폼 경로를 검토한다.
