# Design

Clipboard overlay for Windows and macOS.

- Type: Pretendard, Apple SD Gothic Neo, Malgun Gothic, system-ui
- Primary: `#0f766e`
- Radius: 10px overlay, 12px preference cards
- Theme: Auto / Light / Dark via Ant Design algorithm
- Surface: compact floating panel, keyboard-first

## Preference window

Each tab and section has its own accent. Accents are saturated hues at 10–16% wash so light and dark both keep contrast.

| Tab | Accent |
|---|---|
| record | teal |
| organize | amber |
| reuse | violet |
| workflow | sky |
| shortcuts | rose |
| data | indigo |

Section cards: 5px left stripe, tinted header, colored icon chip, soft shadow. Section nav uses colored pills, not a single teal underline.
